## TP2 - Portfolio Multipágina con React Router DOM

## Alumno: Joel Cuevas
## Comisión: 5
## Materia: Programación 4

## Descripción

Continuación del portfolio del TP1, convertido en una aplicación multipágina con menú lateral (~30%) y área de contenido (~70%). La navegación se resuelve con React Router DOM, sin recargar la página.

Páginas: Inicio (`/`), Sobre mí (`/about`), Habilidades (`/skills`), Proyectos (`/projects`) y Contacto (`/contact`).

## Tecnologías

- React 18 + Vite
- React Router DOM
- JavaScript, JSX y CSS

## Instalación

```bash
npm install
```

## Ejecución local

```bash
npm run dev
```

Luego abrir la URL que muestra la terminal (por defecto http://localhost:5173).
